Competitive Programming

Data structures, Algorithms roadmaps, and practice platforms guide.

CP Learning Guidelines

  • Start with arrays, loops, strings, and sorting.
  • Master basic data structures: stack, queue, map, set, and vector.
  • Practice 10–15 problems per topic before moving on.
  • Use Codeforces, HackerRank, and CSES for regular practice.
  • Focus on debugging, complexity analysis, and clean logic.

Web Development

Frontend and Backend tracks with useful documentation links.

Web Development Guidelines

  • Learn HTML, CSS, and JavaScript before frameworks.
  • Build small projects: portfolio, to-do app, and login page.
  • Understand responsive design, DOM manipulation, and fetch APIs.
  • Practice backend basics: PHP, MySQL, CRUD operations, and sessions.
  • Use MDN, W3Schools, and official docs to confirm concepts.
